## 价格杠杆与成本约束驱动兼容耗材市场历史规模演进

价格杠杆决定了行业早期扩张的方向与速度。20世纪70-80年代打印机商业化后，原装体系依赖"设备低价、耗材高价"获取利润，兼容替代在20世纪80-90年代获得生存空间；进入2000-2010年后，渠道端可感知的30%-60%价差持续稳定，替代行为由零散试用升级为常态采购，市场由此进入规模化阶段。最终在2024年形成约176亿美元体量，且在CR5仅8.45%、头部仅2.3%的低集中度格局下仍保持扩容，说明增长不是个别品牌的偶发成功，而是长期成本约束、预算压力与复购逻辑共同作用的结果。按时间拆分，70-80年代是需求启蒙，80-90年代是替代验证，2000-2010年是加速放量，2010年至今是质量与品牌并进，这条链路完整解释了历史规模为何能跨周期延续。
