## 中国油污净行业市场分析

### 行业概述

油污净是针对油烟机、排气扇、燃气灶、瓷砖、玻璃、水池、微波炉内部的金属表面等重油污场景而设计的专用清洁剂产品。油污净可在不伤害用具表面的前提下，对粘稠、附着力极强的油垢进行清除，达到清洁目的。

### 行业市场规模

中国油污净行业作为家庭清洁细分市场的重要组成部分，近年来受益于消费者卫生意识提升和产品创新，呈现出稳健增长态势：

| 年份 | 市场规模（亿元） | 销量（万瓶） |
|------|--------------|------------|
| 2020 | 10.3 | 10,271.7 |
| 2024 | 18.2 | 18,168.0 |
| 2029（预测）| 27.0 | 26,986.9 |

2020年至2024年，市场规模年复合增长率（CAGR）达**15.3%**。

### 产业链分析

**上游：原材料与设备供应商**
- 原材料成本占比较高，主要包括化学品及包装材料
- 棕榈油是提炼化学品的最重要原材料，LDPE为最重要的包装材料之一
- 预计未来原材料价格将进入下行通道，推动中游厂商盈利能力改善

**中游：油污净产品生产制造商**
- 市场集中度较高，2024年行业CR5超过60%
- 行业正经历从基础清洁向功能细分转型
- 头部企业通过长期供应商协议和期货工具对冲原材料价格波动风险

**下游：零售渠道商及终端消费者**
- 线上、线下销售额各自占比近50%（2024年）
- 线上渠道占比由2019年的22.8%增长至2024年的50%，年复合增长率17.0%
- 内容电商销售增量为全渠道最快
- 2024年中国厨房清洁用品人均消费支出达38.4元，同比增长9.4%

### 市场竞争格局

中国油污净行业呈现高度集中的市场竞争格局，头部品牌占据主导地位：

- **行业前五名品牌合计市占率高达81.2%**（2024年1月至2025年8月线上渠道销量）
- 净浮生以28.8%的市场份额位居行业第一
- 其他主要品牌包括威猛先生、蓝月亮等

### 增长驱动因素

1. 全球公共卫生事件加剧家庭对厨房环境的卫生关注
2. 消费者生活水平提高及健康意识增强
3. 供应链完善与产品技术迭代降低生产成本
4. 电商渠道快速发展提供更便捷购买途径
5. 产品形态升级：抗菌、护手、无残留等附加特性产品占比持续提升

### 未来展望

- 行业预计将保持稳健增长，2029年市场规模有望达到27.0亿元
- 中国厨房清洁用品人均消费支出与美国、日本相比仍有较大差距，未来增长空间广阔
- 行业竞争将从"规模驱动"向"市场与技术双轮驱动"转型
- 产品创新与品牌建设将成为差异化竞争的关键
